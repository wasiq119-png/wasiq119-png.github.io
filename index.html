AI Software House

Overview

A fully autonomous 7-agent system that generates complete websites from a single natural-language prompt. The Manager agent decomposes the task and dispatches Designer, Developer, QA, SEO, Security, and Deploy agents in a coordinated pipeline.

How It Works

Each agent operates on a specialised context window. The Manager orchestrates via function-calling, the Designer produces wireframes, the Developer writes JSX, the QA agent runs automated tests, and the Deploy agent pushes to a live CDN — all in one pass averaging 13,751 tokens.

Tech Stack

LangChain GPT-4o React Vite Node.js Multi-Agent Function Calling

AI Job Assistant

Overview

A live production tool that analyses CVs against job descriptions, extracts keyword matches, computes a semantic fit score (0–100%), and generates personalised cover letters using Groq LLM.

Architecture

React frontend communicates with a Spring Boot backend. CV text is parsed, vectorised, and compared against job description embeddings. Groq's low-latency API powers the cover letter generation in under 2 seconds.

Tech Stack

React Spring Boot Groq LLM PostgreSQL Java Docker

DataOps Microservices

Overview

An event-driven microservices architecture for real-time data pipeline processing. Features Kafka message brokering, Prometheus + Grafana observability, and Docker Swarm orchestration.

Architecture

Six independent Spring Boot services communicate via Kafka topics. Each service has its own PostgreSQL schema. Prometheus scrapes metrics, Grafana visualises them. Docker Swarm handles rolling deploys and auto-scaling.
